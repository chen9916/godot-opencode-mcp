# Portable deployment

Use this when you want to copy the OpenCode Godot MCP bridge to another PC without rebuilding it there.

## Build the portable folder

From `misc/opencode_mcp_bridge` on the build machine:

```bash
npm ci
npm run portable
```

The output is written to:

```text
portable/godot-opencode-mcp-bridge
```

That folder contains the compiled bridge, production `node_modules`, launcher scripts, and package metadata.

## Copy to another PC

Copy the whole `portable/godot-opencode-mcp-bridge` folder to the target PC.

The target PC still needs:

- Node.js 20+ available as `node` on `PATH`.
- OpenCode installed.
- A Godot editor build that includes `editor/debugger/opencode_mcp`.

## One-command setup on the target PC

Open a terminal in the copied folder and run one of these:

```powershell
.\setup.ps1 --project-root "C:\path\to\godot\project"
```

```cmd
setup.cmd --project-root "C:\path\to\godot\project"
```

```bash
./setup.sh --project-root "/path/to/godot/project"
```

The setup command validates Node.js, checks the bundled bridge runtime, installs `mcp.godot-opencode` into the current user's OpenCode config using the copied folder's absolute path, and prints the remaining Godot editor steps.

If you want only the config install step, use one of these:

```powershell
.\install-opencode-config.ps1 --project-root "C:\path\to\godot\project"
```

```cmd
install-opencode-config.cmd --project-root "C:\path\to\godot\project"
```

```bash
./install-opencode-config.sh --project-root "/path/to/godot/project"
```

The installer writes `mcp.godot-opencode` into the current user's OpenCode config using the copied folder's absolute path.

Use `--config-path "<path>"` to target a non-default OpenCode config file. Use `--session-file "<path-to-session.json>"` only when you do not want session auto-discovery.

## Runtime requirements

Before using the MCP tools:

- Open the project in the custom Godot editor.
- Enable `Editor Settings -> network/opencode_mcp/enabled`.
- Restart OpenCode after installing the config entry.

The bridge discovers `.godot/opencode_mcp/session.json`, which is generated by the running Godot editor. Do not copy this session file between machines.

## Source checkout setup

If you copied the full Godot source tree instead of the portable folder, run this from the repository root:

```powershell
.\setup-godot-opencode-mcp.ps1 --project-root "C:\path\to\godot\project"
```

```cmd
setup-godot-opencode-mcp.cmd --project-root "C:\path\to\godot\project"
```

```bash
./setup-godot-opencode-mcp.sh --project-root "/path/to/godot/project"
```

From a source checkout, setup runs `npm ci`, builds the bridge, installs OpenCode config, and reports whether a built Godot binary was found under `bin/`.
